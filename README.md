# Paul Skenes 投手分析（2025年）

2025年にサイ・ヤング賞を満票で受賞したポール・スキーンズの投球を、データで読み解いた分析です。

📝 詳細な解説（note）: https://note.com/tome_baseball/n/nd346073346bc

## 分析の問い

- なぜ、スキーンズは満票でサイ・ヤング賞を獲得したのか？
- 2024年（新人王）と比べて、投球内容は何が変わったのか？

## 使用データ

- MLB公式のStatcastデータ、Baseball Referenceの成績データ（CSVをダウンロードして使用）
- 対象期間：2024年・2025年シーズン
- 取得日：【2026年 9月27日～9月29日】

## 使用ツール

- Google Colab（Python / pandas）
- SQL（【SQLiteなど、実際に使ったものを書く。不明なら「Colab上でSQLによる集計を実施」と書く】）

## 分析の流れ

1. 公式サイトからCSVをダウンロードし、Colabに読み込む
2. SQLで必要な指標を抽出・集計する（【例：球種別の集計、年度別の比較】）
3. pandasで表を整形し、グラフを作成する
4. 結果を解釈し、noteの記事にまとめる
