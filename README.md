# Paul Skenes 投手分析

## 概要

MLB選手ポール・スキーンズの2025年シーズンの投球データを用いて、満票でサイ・ヤング賞を受賞した理由について分析しました。

2025年の投手成績に加え、K%（奪三振率）、BB%（与四球率）、Whiff%（空振り率）、Hard-Hit%（強い打球の割合）、xwOBA（期待加重出塁率）などの指標を用いて、スキーンズの投球の特徴を分析しました。

また、2024年の新人王を獲得したシーズンと比較し、投球内容や成績の変化にも注目しました。

## 分析テーマ

### 1. サイ・ヤング賞を獲得した2025年

2025年の防御率、投球回、奪三振数、WHIP、WARなどの投手成績を整理し、スキーンズが残した成績を分析しました。

また、主要な投手成績のリーグ内順位にも注目し、特定の指標だけでは捉えきれないシーズン全体の価値について考察しました。

### 2. 数字の裏側から見る、スキーンズの投球
